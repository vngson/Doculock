# Export & Reporting

Generate comprehensive reports and export verification data in multiple formats. Create audit trails, maintain records, and share verification results with stakeholders.

<Callout type="info">
  Export options are available after batch verification or from the document history view.
</Callout>

## Export Formats [#export-formats]

### PDF Reports

Professional, printable PDF reports containing:

- **Summary Statistics**
  - Total documents processed
  - Success/failure counts
  - Average file size
  - Processing duration

- **Detailed Table**
  - Document names
  - SHA-256 hashes
  - File sizes
  - Verification status
  - Timestamps
  - Transaction IDs

- **Visual Elements**
  - Company/logo header
  - Status indicators
  - Timestamp formatting
  - Page numbers

<Callout type="success">
  PDF reports are ideal for audits, compliance, and legal documentation.
</Callout>

### CSV Data

Spreadsheet-compatible CSV format:

```csv
FileName,FileSize,Hash,Status,Timestamp,TxDigest
document1.pdf,1024000,a1b2c3d4...,verified,2024-01-15T10:30:00Z,0xabcd...
document2.png,2048000,e5f6g7h8...,verified,2024-01-15T10:31:00Z,0xefgh...
```

Features:
- **Universal compatibility** - Works in Excel, Google Sheets, etc.
- **Raw data** - No formatting complications
- **Easy processing** - Import into databases
- **Compact size** - Minimal file size

### JSON Export

Machine-readable JSON format:

```json
{
  "metadata": {
    "exportDate": "2024-01-15T10:30:00Z",
    "totalDocuments": 20,
    "successCount": 18,
    "failedCount": 2
  },
  "documents": [
    {
      "fileName": "document.pdf",
      "fileSize": 1024000,
      "hash": "a1b2c3d4...",
      "status": "verified",
      "timestamp": "2024-01-15T10:30:00Z",
      "txDigest": "0xabcd...",
      "creator": "0x1234..."
    }
  ]
}
</Code>

Use cases:
- **API integration** - System-to-system transfers
- **Data processing** - Custom scripts
- **Archiving** - Long-term storage
- **Analysis** - Data mining

## Generating Exports [#generating-exports]

### After Batch Verification

1. Complete batch upload/verification
2. Click **"Export Results"** button
3. Select export format
4. File downloads automatically

### From Document History

1. Navigate to **History** tab
2. Apply filters (optional)
3. Click **"Export"** button
4. Choose format and date range
5. Download generated file

### API Export

```bash
POST /api/export
Content-Type: application/json

{
  "format": "pdf",
  "startDate": "2024-01-01",
  "endDate": "2024-01-31",
  "creator": "0x1234..."
}
```

## Security Considerations [#security-considerations]

### Data Protection

When exporting:

- **Redact sensitive info** - Remove private data
- **Use secure transfer** - Encrypted channels
- **Access controls** - Authorized recipients only
- **Secure storage** - Encrypted at rest

### Hash Privacy

Consider hash exposure:

- **Hashes are public** - Visible on blockchain
- **No content exposure** - File remains private
- **Reverse protection** - Can't recover content
- **Collision resistance** - Secure hashing

<Callout type="warning">
  Exports contain public blockchain data. Ensure recipients are authorized.
</Callout>

## Troubleshooting [#troubleshooting]

### Export Fails

If export generation fails:

1. Check data availability
2. Verify date ranges
3. Reduce result set
4. Check API status

### File Too Large

If export file is too large:

1. Narrow date range
2. Apply filters
3. Use CSV instead of PDF
4. Split into batches

### Missing Data

If export has missing documents:

1. Verify sync status
2. Check indexer health
3. Confirm blockchain events
4. Re-run export
