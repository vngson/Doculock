# Analytics Dashboard

The DocuLock Analytics Dashboard provides real-time insights into document verification activity on the platform. View statistics, trends, and patterns to understand platform usage and network activity.

<Callout type="info">
  Analytics data is fetched from MongoDB indexer for optimal performance, ensuring accurate and up-to-date information.
</Callout>

## Overview [#overview]

The dashboard displays key metrics:

- **Total Documents**: Number of documents stored on blockchain
- **Unique Users**: Count of distinct wallet addresses
- **Total Storage**: Combined size of all documents
- **Recent Activity**: Uploads in the last 24 hours

- Schedule maintenance

- Resource planning

## Performance Optimization [#performance-optimization]

### Caching Strategy

- **API response caching** - 5-minute TTL
- **Client-side caching** - Browser storage
- **Invalidation** - On new document events
- **Refresh interval** - Configurable

### Indexing Strategy

MongoDB indexes for fast queries:

- `idx_timestamp` - Sort by date
- `idx_creator` - Filter by user
- `idx_file_size` - Size queries
- `idx_timestamp_creator` - Compound index

<Callout type="success">
  Proper indexing ensures sub-100ms query times even with thousands of documents.
</Callout>

## Troubleshooting [#troubleshooting]

### Data Not Updating

If analytics seem stale:

1. Click **"Refresh"** button
2. Check indexer status
3. Verify MongoDB connection
4. Try **"Resync"** as last resort

### Empty Dashboard

If no data appears:

1. Verify indexer is running
2. Check blockchain events
3. Confirm MongoDB has data
4. Check API endpoints

### Slow Loading

If dashboard is slow:

1. Check network connection
2. Verify indexer performance
3. Check MongoDB indexes
4. Consider pagination

<Callout type="info">
  See [Indexer Documentation](/indexer) for troubleshooting indexer-specific issues.
</Callout>
