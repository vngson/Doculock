# Quick Start [#quick-start]

Get DocuLock up and running in 5 minutes. Upload your first document, verify it, and generate a shareable proof.

<Callout type="info">
This guide assumes you've completed the [Setup Guide](/guides/setup) and have a running development server.
</Callout>

## Step 1: Connect Your Wallet [#connect-wallet]

1. Click the Sui wallet icon in the top-right corner
2. Select your wallet extension (Sui Wallet, Suiet, etc.)
3. Approve the connection request

<Callout type="warning">
Make sure you're on testnet and have testnet SUI tokens for gas fees.
</Callout>

## Step 2: Upload a Document [#upload-document]

### 2.1 Navigate to Upload Tab
Click the "Upload" tab in the main navigation.

### 2.2 Select a File
Drag & drop any file (PDF, image, text, or any document type) into the dropzone, or click to browse.

### 2.3 Review Document Details
The app will automatically:
- Calculate SHA-256 hash client-side
- Detect file type and size
- Generate a preview

### 2.4 Store on Blockchain
Click "Store on Blockchain" and sign the transaction in your wallet.

<Callout type="success">
Success! Your document hash is now immutably stored on the Sui blockchain.
</Callout>

## Step 3: Verify a Document [#verify-document]

### 3.1 Navigate to Verify Tab
Click the "Verify" tab in the main navigation.

### 3.2 Upload the Same File
Upload the original file again (or use any file that you want to verify).

### 3.3 Check Verification Status
Click "Verify on Blockchain" to see:
- ✓ **Verified** - Document exists on blockchain with matching hash
- ✗ **Not Found** - Document has not been registered

## Step 4: View Document History [#view-history]

### 4.1 Navigate to History Tab
Click the "History" tab to see all your uploaded documents.

### 4.2 Review Document Details
Each document shows:
- File name and type
- Upload timestamp
- Verification status
- File size
- QR code button

### 4.3 Share Verification Proof
Click the QR code icon to generate a shareable proof:
- Scan with mobile device
- Shows document hash and blockchain timestamp
- Independent verification possible

## How It Works [#how-it-works]

DocuLock uses a secure, privacy-preserving workflow:

<Mermaid
  chart="sequenceDiagram;
participant User
participant Browser
participant Blockchain

User->>Browser: Upload file
Browser->>Browser: Calculate SHA-256 hash
Browser->>Blockchain: Store hash (transaction)
Blockchain-->>Browser: Confirmation + timestamp
Browser->>Blockchain: Verify hash (query)
Blockchain-->>Browser: Exists/Not Found
Browser->>User: Show verification result;"
/>

**Key Points:**
- File content never leaves your device unhashed
- Only cryptographic hash stored on-chain
- Timestamp provides immutable proof of existence
- Anyone can verify independently

## Common Workflows [#common-workflows]

### Verify Document Authenticity
Use case: Confirm a document hasn't been modified

1. Get the original document
2. Upload to DocuLock
3. If verified, document is authentic and unchanged

### Prove Document Existence
Use case: Show when a document was created

1. Upload document immediately upon creation
2. Share QR code as proof of timestamp
3. Anyone can verify independently

### Batch Verification
Use case: Verify multiple documents at once

1. Click "Batch Verify" tab
2. Select multiple files
3. Export verification report (PDF/CSV)

## Troubleshooting [#troubleshooting]

**"Registry not found"**
- Check your `.env.local` configuration
- Verify smart contract was deployed successfully

**"Transaction failed"**
- Ensure you have sufficient testnet SUI
- Check wallet is connected to testnet
- Try increasing gas budget

**"Hash mismatch"**
- File has been modified since upload
- Ensure you're verifying the exact same file
- Hash is calculated from entire file content
