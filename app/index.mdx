# Welcome to DocuLock

<img alt="DocuLock - Proof of Existence" src="/logo.png" />

**DocuLock** is a blockchain-based document verification platform built on the Sui network that provides immutable proof of existence for your important documents. Upload any document, calculate its SHA-256 hash, and store it permanently on the blockchain for future verification.

<Callout type="info">
  DocuLock uses the Sui blockchain's high-performance infrastructure to provide fast, secure, and cost-effective document verification.
</Callout>

## What is DocuLock? [#what-is-doculock]

DocuLock transforms document verification into a trustless, transparent process. By storing document hashes on the Sui blockchain, you create:

- **Immutable Timestamps**: Prove when a document existed
- **Tamper-Proof Verification**: Any modification changes the hash
- **Decentralized Trust**: No single point of failure or control
- **Legal Admissibility**: Blockchain evidence is increasingly recognized in courts

## Key Features [#key-features]

### Secure Hash Storage

## How It Works [#how-it-works]

### Flow Overview

```
Upload Document → Calculate SHA-256 Hash → Store on Sui Blockchain → Generate QR Code
                                    ↓
Share for Verification → Verify on Blockchain → Hash Match?
                                    ↓
                    Yes → Document Authentic
                     No → Document Modified
```

### The Verification Process

1. **Upload**: Select any document (PDF, images, text files, etc.)
2. **Hash**: Calculate the SHA-256 cryptographic hash
3. **Store**: Submit the hash to the Sui blockchain via smart contract
4. **Share**: Generate a QR code containing the verification link
5. **Verify**: Anyone can verify the document's authenticity independently

## Getting Started [#getting-started]

1. **Connect Wallet**: Connect your Sui wallet (Sui Wallet, Suiet, or other compatible wallets)
2. **Create Registry**: Create a document registry (one-time setup) to store your documents
3. **Upload Document**: Select your document and upload it to calculate its hash
4. **Store on Blockchain**: Sign the transaction to store the hash on the Sui blockchain
5. **Verify Anytime**: Use the Verify tab or QR code to verify document authenticity

## Security & Privacy [#security]

<Callout type="warning">
  **Important**: DocuLock only stores the cryptographic hash of your document, not the document itself. Your file content never leaves your device.
</Callout>

### Security Features

- **Client-Side Hashing**: All cryptographic operations happen in your browser
- **No File Storage**: Documents are never uploaded to any server
- **Immutable Records**: Once stored, hashes cannot be modified or deleted
- **Cryptographic Proof**: SHA-256 ensures any change is detectable
- **Wallet Security**: All blockchain transactions require wallet signature

## Use Cases [#use-cases]

### Legal Documents
Attorneys and law firms can prove the existence of contracts, wills, and legal agreements at specific points in time, providing evidence in disputes.

<Callout type="success">
  **New Feature**: Verify multiple documents at once! Upload folders or ZIP archives to process hundreds of documents efficiently.
</Callout>

### Batch Verification Capabilities

- **Multi-file Upload**: Select individual files, entire folders, or ZIP archives
- **Parallel Processing**: Web Workers enable concurrent hash calculation
- **Progress Tracking**: Real-time progress bar for each file
- **Comprehensive Reports**: Export results as PDF, CSV, or JSON
- **Error Handling**: Individual file failures don't stop the entire batch
